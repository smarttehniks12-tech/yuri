# НЕБЕСНОЕ ОГРАНИЧЕНИЕ — «Что, если ты станешь Тоджи Фусигуро?»

Анимационная мини-история на 90 секунд в духе аниме-экшена: обычный человек просыпается без капли проклятой энергии и превращается в Тоджи Фусигуро. Сделано целиком на **HTML5 + Canvas 2D + JavaScript** без библиотек: персонажи нарисованы кодом и анимированы «на костях», каждый кадр — чистая функция времени.

**Готовое видео:** `video/toji_heavenly_restriction_9x16.mp4` — вертикальное 1080×1920, 30 к/с, H.264 + AAC, 1:30. Подходит для YouTube Shorts, Reels и TikTok.

## Как посмотреть в браузере

```bash
cd toji-animation
python3 -m http.server 8080
# откройте http://localhost:8080
```

Управление: **▶ / ❚❚** или пробел — воспроизведение и пауза, **↺** или `R` — перезапуск, ползунок и стрелки — перемотка, **CC** — субтитры, **HQ** — motion blur (нужна мощная видеокарта), **⛶** — полный экран. Часы плеера — звуковая дорожка, поэтому картинка всегда синхронна с озвучкой.

## Сценарий и планы (≈45 планов)

| Время | Сцена | Что происходит |
|---|---|---|
| 0–9 | Неожиданное начало | Спальня, рассвет, пылинки в луче. Парень просыпается и садится, крупный план сонного лица, вид от первого лица на ладони: синие нити проклятой энергии тают. Чёрный титр «НЕБЕСНОЕ ОГРАНИЧЕНИЕ» с низким ударом. |
| 9–24 | Изменения тела | Кулак сжимается, проступают вены (удары сердца) → бицепс наливается силой, камера скользит к плечу → торс под натянутой футболкой → силуэт у окна выпрямляет осанку → падающий стакан пойман в воздухе → лицо становится жёстким, появляется шрам → зрачок сужается, «взгляд хищника». |
| 24–39 | Первые способности | Тренировочная площадка: кран вниз, шаг крупно, нога продавливает камень → рывок с кратером, послеобразами и «хлыстом» камеры → прыжок выше крыш с солнцем в зените → приземление с ударной волной и импакт-кадрами → удар разносит бетонный столб → небо темнеет, в воздухе раскрывается разлом. |
| 39–57 | Насколько ты опасен | Через плечо героя: проклятый дух падает из разлома → рёв крупно → рывок → взмах когтей → замедление: когти в сантиметрах от лица → глаз с отражением когтей → послеобраз, герой уже за спиной → удар (импакт-кадры) → враг пробивает здание → «Один удар. И всё закончено.» → враг рассыпается пеплом. |
| 57–75 | Настоящая сила | Ночь. Со спины, камера обходит (склейка через обломок) → лицо в три четверти со шрамом → низкий ракурс на фоне луны → «слышишь каждый шорох» (круги звука) → глаз открывается → время замедляется: костяные шипы, он ловит один двумя пальцами → время возвращается, шипы взрываются о стену. |
| 75–90 | Финал | Разрушенная площадка на закате → герой поднимает голову → лицо, лёгкая ухмылка → чёрный силуэт на фоне солнца и название. Резкая чернота и финальный удар. |

## Звук

* **Озвучка — ElevenLabs**, один голос на весь ролик: **«Evgeniy Rybakov»** из библиотеки голосов ElevenLabs (молодой, энергичный, харизматичный русский мужской голос для соцсетей), модель `eleven_v4` с аудиотегами интонации. 7 реплик, по 2 дубля на реплику, выбраны лучшие (`voice/vo1…vo7.mp3`).
* **Звуковые эффекты** — сгенерированы в ElevenLabs (`eleven_text_to_sound_v2`): «браам», сердцебиение, рывок, приземление, разрушение бетона, удар в здание, замедление времени, рёв (`sfx/`). Плюс эффекты удара из основного проекта репозитория.
* **Музыка** — процедурная (Web Audio): пэды, тайко, басовые «браамы», остинато, флейтовая тема в ре-миноре. Под голосом музыка автоматически приглушается, в моменты замедления уходит под фильтр.
* Сведение: `js/mix.js` → громкость −14 LUFS, true peak −1 dB (стандарт соцсетей).

## Как это сделано

* `js/hero.js` — персонаж на костях (вид сбоку: таз, торс, шея, плечо/предплечье/кисть, бедро/голень/стопа) и вид спереди/сзади. Параметр `bulk` плавно превращает обычного парня в Тоджи; одежда: футболка → облегающая тёмная футболка и свободные светлые штаны.
* `js/face.js` — лицо с поворотом головы: черты лежат на эллипсоиде, поэтому нос, глаза, рот и контур корректно смещаются при повороте; профиль и макро-глаз для сверхкрупных планов.
* `js/shade.js` — аниме-сел-шейдинг: полутень от ключевого света, контровой свет, мягкий объём к краям, контур; режимы силуэта и импакт-кадров.
* `js/env.js` — 2.5D-камера (перспективная проекция земли, построек, столбов), небо для четырёх времён суток, спальня.
* `js/fx.js`, `js/post.js` — пыль, обломки, ударные волны, линии скорости, послеобразы; цветокоррекция, свечение, виньетка, плёночное зерно, субтитры.
* `js/director.js` — таймлайн планов, наплывы, **настоящий motion blur** (усреднение субкадров во времени) и вертикальное кадрирование 9:16.
* `js/shots1…4.js` — постановка всех планов; `js/timing.js` — единый таймлайн для картинки, озвучки и звуков.

## Пересборка

```bash
node tools/build-audio.cjs                 # сведение звука → audio/soundtrack.wav и .m4a
node tools/render.cjs video/out.mp4 4      # покадровый рендер в Chromium → MP4 (4 потока)
node tools/stills.cjs /tmp/st 12.5 49.45   # отдельные стоп-кадры для проверки
```

Нужны Node.js, Playwright (Chromium) и ffmpeg.
